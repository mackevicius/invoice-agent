# Triage labels

Map each canonical role to its label in this repo's issue tracker.

| Role              | Tracker label     | Meaning                                       |
| ----------------- | ----------------- | --------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation needed                  |
| `needs-info`      | `needs-info`      | Waiting on the reporter                       |
| `ready-for-agent` | `ready-for-agent` | Fully specified for autonomous implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation                 |
| `wontfix`         | `wontfix`         | Will not be actioned                          |

When a skill mentions a role, use its mapped label. Edit the tracker-label column to change the vocabulary later.
